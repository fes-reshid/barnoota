PDF Editor & Cutter

Merge, reorder, rotate, crop, annotate and cut PDFs — right here in your browser. Your files never leave your device.

Drop PDF files here

or choose one or more files to start. Several files are joined in the order you add them.

Open a PDF from a link

Paste the web address of a PDF file and it will open here for editing.

Some websites don't let other sites download their files. If a link won't open, download the PDF and use Upload file instead.

Everything is processed locally — nothing is uploaded to any server.

All tools

Pick a tool, then click or drag on any page. Added text, white-out and highlights can be moved with Select.

See every page as a thumbnail to reorder (drag), rotate, duplicate, delete or add blank pages.

Add more PDFs — their pages go after the current page.

Drag a box on a page, then choose to crop the page to it, copy or save it as an image, or copy its text. Right-click a page for the same options.

Drag over the text on a page to select it, then press Ctrl+C (or right-click → Copy).

⚠ This PDF's text can't be copied. Its fonts don't record the real letters, so it would paste as symbols. Use Crop → Copy image instead.

File name

Your browser can't show a “Save as” window here, so files go to its Downloads folder. To choose a location every time, turn on “Ask where to save each file” in your browser's download settings.

⚠ White-out only hides text from view. The covered text is still inside the file and can be copied, searched or recovered. Do not use it to remove private information.
