How classes work

  1. Create a class and you get a 6-letter class code.
  2. Give the code to your students — they type it in Tajweed Quest under “From your teacher → My class”. Or add them yourself here.
  3. When you post an announcement, quiz or message, choose the class it’s for. Other classes won’t see it.
  4. On the Students tab, pick a class to see only those students.
