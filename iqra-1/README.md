IQRA 1 ADVENTURE — DIIN ISLAAM

This course is designed to sit at /iqra-1/ in the fes-reshid/barnoota GitHub Pages repository. It uses the existing shared KidsCloud authentication, so learners sign in with their current Tuhfatul Atfaal / Seeraa Quest / Qur'an Tracker username and password. Iqra course progress is saved separately under the `iqra-1` game key.

The learning journey has 16 map tabs, each with a winding road and five lesson stops. Maps and lesson stops unlock as the student completes the previous map/lesson. The interface follows Tuhfatul Atfaal's parchment, gold, green, Marcellus and Amiri design language.

Tapping a stop opens a Tuhfatul-style lesson screen: a blue side panel (map/lesson, coins, home/sound/restart tools and a step list with ticks) and one activity at a time with a step counter and progress bar. Lessons 1–4 go Meet (each letter one by one) → Draw (trace each letter over a grey guide with a finger; the drawing is checked against the letter shape and earns 1–3 stars) → Match them all → Letter Detective → Reward. Lesson 5 goes Listen to every letter → Repeat → Match them all (in rounds of up to six) → Reward. Each lesson's letters come from the map's `focus` list (for example Map 1 Lesson 2 is just Alif). Teachers signed in through the Teacher button can open any lesson to preview it.

The Teacher button uses an existing approved teacher/admin account. It opens a teacher-only lesson editor and audio studio with two tabs: "Lesson sounds" (record/upload one clip per lesson stop, as before) and "Letter sounds" (record or upload a pronunciation clip for each of the 28 Arabic letters, plus each letter combined with Fatha, one at a time). Clips are saved in the shared KidsCloud course content and load for signed-in learners.

Every Arabic letter (and letter+Fatha combination) shown anywhere in the course — in a lesson, or in the Listen & Repeat page — is tappable by students. Tapping plays the teacher's recorded sound for that letter (a 🔊 badge shows which letters already have one); if nothing has been recorded yet, the student sees a gentle reminder to ask their teacher. Letter sounds also play as a reward when a student finds the right letter in the Letter Detective game.

The map titles follow Iqra Book 1 pages 1–30 based on the referenced page-by-page guide, plus pages 33–34 for Map 16, which introduces the Fatha vowel mark (a short "a" sound) on every letter. Lesson text is editable by teachers.
