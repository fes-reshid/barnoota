IQRA 1 ADVENTURE — DIIN ISLAAM

This course is designed to sit at /iqra-1/ in the fes-reshid/barnoota GitHub Pages repository. It uses the existing shared KidsCloud authentication, so learners sign in with their current Tuhfatul Atfaal / Seeraa Quest / Qur'an Tracker username and password. Iqra course progress is saved separately under the `iqra-1` game key.

The learning journey has 15 map tabs, each with a winding road and five lesson stops. Lesson 5 is Listen & Repeat on Page 2. Maps and lesson stops unlock as the student completes the previous map/lesson. The interface follows Tuhfatul Atfaal's parchment, gold, green, Marcellus and Amiri design language.

The Teacher button uses an existing approved teacher/admin account. It opens a teacher-only lesson editor and audio studio with two tabs: "Lesson sounds" (record/upload one clip per lesson stop, as before) and "Letter sounds" (record or upload a pronunciation clip for each of the 28 Arabic letters, one at a time). Clips are saved in the shared KidsCloud course content and load for signed-in learners.

Every Arabic letter shown anywhere in the course — in a lesson, or in the Listen & Repeat page — is tappable by students. Tapping plays the teacher's recorded sound for that letter (a 🔊 badge shows which letters already have one); if nothing has been recorded yet, the student sees a gentle reminder to ask their teacher. Letter sounds also play as a reward when a student finds the right letter in the Letter Detective game.

The map titles follow Iqra Book 1 pages 1–30 based on the referenced page-by-page guide. Lesson text is editable by teachers.
