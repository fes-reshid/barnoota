What is Noor Shield?

Noor Shield is a free Windows app built for families who want two things at once: a real technical barrier against adult content on a shared or a child's computer, and gentle Islamic reminders that speak to the reason for wanting that barrier in the first place — lowering the gaze, remembering the Ākhirah, and turning back to Allah through tawbah (repentance) and istighfār (seeking forgiveness).

It is not a spying tool and it is not a productivity blocker. It has one job: stop this PC from reaching a list of known adult-content websites, whichever browser or app tries to reach them, and let a parent see — only if they choose to check — what it has been blocking.

What it actually does

Four things, working together:

FeatureWhat it means in practice
Website filter Blocks a curated list of known adult-content domains for the whole PC — every browser, every app — not just one browser's settings. Runs as a Windows background service, so it keeps working even after you close the app window, log off, or restart the computer.
Parent password Set once, on first run. Required to turn the filter off, add or remove blocked sites, or remove Noor Shield entirely. A one-time recovery key is shown at setup in case the password is ever forgotten.
Activity log A private, on-this-PC record of sites the filter has actually blocked. Only a parent who knows the password can view or clear it. It is not a full browsing history — see below.
Email reports, on request A parent can connect their own email account once, then click "Send report now" whenever they want a copy of the activity log in their inbox. Nothing is sent automatically or on a schedule — only when that button is clicked.
Islamic reminders Rotating notifications citing authentic Hadith on lowering the gaze, tawbah, and istighfār, plus a private journal for logging moments of repentance.

What it can't do — please read this too

Being honest about limitations is part of what this app is for. None of the following are secrets — they're exactly what you should know before trusting it with something important.

No filter can promise to block everything. This is a real barrier and a real reminder — it is not a replacement for a person's own intention to lower their gaze. Please don't present it to a family as a guarantee.
  • The website list is a starting point, not a complete one. No software can automatically discover every adult website that exists — new ones appear constantly. You can add specific sites yourself once you notice them.
  • A determined adult user can turn it off. Windows itself only lets an administrator account stop or remove background services and change DNS settings — so this is a real, OS-enforced barrier for a child using a standard (non-administrator) account, but not against someone who has administrator access to the PC, including a parent who forgets they're signed in as one.
  • Some technical bypasses exist. A site reached by typing its raw numeric address, or a browser configured to use its own private DNS settings, can slip past this kind of filter. Turning off "Secure DNS" / "DNS over HTTPS" in Chrome or Firefox's settings closes one of the more common of these gaps.
  • The activity log only shows what the filter actually blocked — it is not a record of every website visited, only the ones that were stopped.
  • Emailing yourself a report sends that list to your email provider. Choose a recipient address you actually control, since that's now a second place this information lives.

Installing it

  1. Go to the Apps page and click Download for Windows under Noor Shield.
  2. Once downloaded, right-click the installer file and choose Run as administrator. (If you just double-click it, Windows may ask you to confirm elevation anyway — say yes. The app needs this to install its background service and adjust DNS settings; it can't do either as a normal user.)
  3. Windows will likely show a blue "Windows protected your PC" screen. This appears for any app that isn't digitally signed yet, not because anything is wrong. Click More info, then Run anyway.
  4. Follow the installer's prompts (choose an install location if asked, or accept the default).
  5. The app opens automatically when installation finishes, and starts its background service. This first launch is where you'll set the parent password — see the next section.
Takes about a minute in total. No account, sign-up, or payment is needed anywhere in this process.

Verifying the download (optional, for the technically inclined)

A checksum file sits next to the installer on the Apps page download link (Noor-Shield-Setup-0.2.8-beta.1.exe.sha256.txt). If you want to confirm your download wasn't corrupted or altered in transit, open PowerShell and run: 

Get-FileHash "Noor Shield Setup 0.2.8.exe" -Algorithm SHA256

The result should match the value in that checksum file.

First-time setup

  1. Set a parent password. This is the one password that matters — it protects the filter settings, the activity log, and the email settings from being changed or viewed by anyone who doesn't know it.
  2. Write down the recovery key shown right after. This is shown exactly once. If the parent password is ever forgotten, this key — and only this key — can reset it. Keep it somewhere the password itself needs protecting from (not saved in an obviously named file on the same PC).
  3. Noor Shield will automatically request Windows' one-time permission to install its background filtering service. Approve it.
  4. The dashboard should now show Protection: Active. That's it — the filter is running.

Using it day to day

Checking it's working

Open the app any time to see the dashboard. "Protection: Active" means the filter is running; a warning banner appears instead if something needs attention (for example, if the app isn't running as Administrator).

Closing vs. quitting

Closing the window sends Noor Shield to the notification area (the small icons near your clock) rather than quitting it — protection keeps running either way, since it lives in a separate background service, not the window itself. Right-click that tray icon for "Open Noor Shield" or a quick "Repair DNS" option.

Adding a blocked site

Go to Blocked sites, type in a website address (just the domain, like example.com — a full link works too), and click Add. It takes effect immediately, without needing to restart anything.

The activity log & email reports

Viewing the log

Open the Activity Log tab and enter the parent password if asked. You'll see a list of blocked attempts with dates and times, and a count of how many total. A Clear log button is available if you want to reset it.

Setting up email reports

  1. In the Activity Log tab, find Email settings.
  2. Enter your email provider's SMTP server details. For most personal Gmail or Outlook accounts, this means generating an app password from your email provider's security settings (search "[your provider] app password" for their exact steps) rather than using your normal login password.
  3. Enter the address you want reports sent to — this can be the same account or a different one you check.
  4. Click Save email settings.
  5. Whenever you want a copy of the activity log in your inbox, click Send report now. Nothing is sent unless you click this — there is no automatic schedule.
The email password is stored encrypted using Windows' own secure credential storage, the same protection Windows itself uses for saved Wi-Fi passwords — not as plain readable text.

If your internet stops working

Noor Shield works by telling Windows to send DNS lookups (the "phone book" that turns website names into addresses) through its own filter first. If the background service ever stops unexpectedly without cleaning up after itself, the PC can be left pointed at a filter that isn't running — which looks like "the internet is down."

  1. Reopen Noor Shield. It automatically checks and repairs this on every launch.
  2. If that doesn't help, right-click the tray icon (near the clock) and choose Repair DNS. This step does not need the parent password — a broken internet connection shouldn't have to wait for whoever set up the app.
  3. As a last resort, an administrator can open PowerShell as Administrator and run: 
    Get-NetIPInterface -AddressFamily IPv4 |
  ForEach-Object { Set-DnsClientServerAddress -InterfaceIndex $_.ifIndex -ResetServerAddresses }
Clear-DnsClientCache

Removing it completely

Simply closing the app does not remove Noor Shield — that's deliberate, so it keeps protecting the PC without needing to be reopened. To actually remove it:

  1. Open Noor Shield and go to Parent settings.
  2. Enter the parent password when asked.
  3. Click Remove protection completely and confirm.

This restores your normal Windows DNS settings and fully uninstalls the background service — not just the app window.

Questions & getting help

Does this app see or store what I actually browse?

No. It only ever records the domains it blocks — sites it stops. Anything you visit that isn't on the blocklist is never logged anywhere by Noor Shield.

Is anything sent to the internet, to Diin Islaam, or to anyone else?

No — with one exception you control entirely: if you set up email reports yourself and click "Send report now," that report goes directly from your PC to the email account you configured, using your email provider. Diin Islaam never receives, stores, or sees any of it.

Will this slow down my internet?

No noticeable difference. It only intercepts the initial address lookup for a website, not the actual browsing traffic afterward.

Does it work on Mac or Linux?

Not currently — this build is for Windows 10 and 11 only. A separate Android version of Noor Shield also exists; see the Apps page.

I found a bug, or something in this guide doesn't match what I see.

Please let us know — this is an early beta and real reports from real installs are exactly what improves it. Reach out via the contact link in the footer of any page on this site.

I want to see the source code or the full technical documentation.

Noor Shield is developed in the open. The complete technical README — architecture details, exact security design, and everything else beyond what a parent needs day to day — is linked from the Apps page alongside the download.
