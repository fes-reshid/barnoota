Admin Sign In

Sign in with the admin account to add students and manage passwords.

First-time setup (do this once)
  1. Create the admin login. In the Firebase Console → Authentication → Users, click Add user and enter the admin email (must match ADMIN_EMAIL in kids-quest-cloud.js — currently fesbackups@gmail.com) and a password of your choice. That's the login you'll use above.
  2. Add the Firestore security rules. In Firebase Console → Firestore Database → Rules, add this block inside your existing match /databases/{database}/documents { ... } (alongside whatever rules already exist for other collections — don't remove those): 
    match /kids_quest_students/{uid} {
  // a student can only ever read/write their own saved progress
  allow get, create, update: if request.auth != null && request.auth.uid == uid;
  // the admin account can manage every student's record
  allow get, list, create, update, delete: if request.auth != null
    && request.auth.token.email.lower() == 'fesbackups@gmail.com';
}
    Replace the email on the last line if you used a different admin address.
  3. Reload this page and sign in above. New student accounts you create will start working immediately.
