Admin Sign In

Sign in with an admin account to add students and manage passwords.

First-time setup (do this once, as the very first admin)
  1. Add the Firestore security rules. In Firebase Console → Firestore Database → Rules, add these two blocks inside your existing match /databases/{database}/documents { ... } (alongside whatever rules already exist for other collections — don't remove those): 
    match /kids_quest_admins/{adminEmail} {
  // anyone signed in can check their OWN admin status
  allow get: if request.auth != null
    && request.auth.token.email.lower() == adminEmail;
  // a super admin can see and manage the whole admin list
  allow get, list, create, update, delete: if request.auth != null
    && get(/databases/$(database)/documents/kids_quest_admins/$(request.auth.token.email.lower())).data.role == 'super';
}
match /kids_quest_students/{uid} {
  // a student can only ever read/write their own saved progress
  allow get, create, update: if request.auth != null && request.auth.uid == uid;
  // any listed admin (super or regular) can manage every student's record
  allow get, list, create, update, delete: if request.auth != null
    && exists(/databases/$(database)/documents/kids_quest_admins/$(request.auth.token.email.lower()));
}
  2. Create the bootstrap super-admin document by hand — this can't be done from inside the app, since nothing can grant the very first admin role from a page that requires already being an admin. In Firebase Console → Firestore Database → Data, start a collection named kids_quest_admins, and add one document:
    • Document ID: savefes@gmail.com (all lowercase, exactly as shown)
    • Field email (string) = savefes@gmail.com
    • Field role (string) = super
  3. Come back here and click "First time here? Create your admin login" below, using savefes@gmail.com and a password of your choice (this is a brand new login — it doesn't matter whether that email has signed into anything on this site before). You're now signed in as the super admin — from here on, adding more admins (regular or super) is done entirely from the Admins section below, no more console work needed.
