Let's connect your admin page

The website is working fine right now — it is reading events from the file assets/events.js. To edit events from this page instead of editing code, connect it to the Firebase project you created. It takes about five minutes, once.

  1. Turn on the two services you need

    In the Firebase console, open your project and enable Authentication (Sign-in method → Email/Password) and Firestore Database (start in production mode). Enable Storage too if you want to upload event posters from this page.

  2. Copy your web config

    Project settings → Your apps → the web app → Config. Paste those values into assets/firebase-config.js in your GitHub repository, replacing the PASTE_… placeholders. They are not secret — every Firebase site publishes them.

  3. Publish the security rules

    Upload firestore.rules and storage.rules from this folder (Firebase CLI: firebase deploy --only firestore:rules,storage). These are what actually protect your data — they let anyone read events, and only listed committee members write them.

  4. Create your admin account

    Authentication → Users → Add user, with your email and a password. Then in Firestore create a collection called admins and add a document whose Document ID is that user's UID (copy it from the Users list). Put one field in it: email. Repeat for each committee member who should have access.

  5. Come back and sign in

    Reload this page. You will get a login box, and then you can add and edit events here.

Full instructions, including the exact commands, are in ADMIN-SETUP.md.
