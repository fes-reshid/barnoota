Security in one place

Find problems, then decide

Seven tools that look, explain in plain words and only act when you press a button.

1

Virus scan

Runs NoorGuard's own checks for known malware, disguised programs and USB worms, plus an optional full Microsoft Defender scan.

  • A green live scan screen with soft sounds
  • Threats show in red, with the reason
  • Quarantine locks threats away and can restore them
2

Network & ports

See which doors your PC has open, which program uses each one and who is connected. Block what you do not want with Windows Firewall.

  • A risk level and a plain explanation for each port
  • Block a port or one address; stop the program using a port (never essential Windows programs)
  • Every block is listed and can be removed
3

Attack detection and live protection

Spots port scans, floods of connections and password guessing, warns you, and keeps watching from the tray with the window closed.

  • Checks every 30 seconds while it is running
  • Warns you; it never blocks by itself
  • An attack history, and an optional country lookup (online, off by default)
4

Security check

Firewall, virus protection, updates, UAC and drive encryption, each with a fix button. Then the places malware hides and starts from.

  • Hiding places: startup entries, scheduled tasks, services
  • The hosts file, browser extensions and proxy settings
  • Remote access: Remote Desktop and remote-control tools
5

Devices and your router

Find every device on your Wi-Fi, mark the ones that are yours and spot strangers. Checks the router for weak doors and gives you a checklist.

  • New devices are flagged until you say they are yours
  • Looks for risky router doors such as Telnet
  • Never tries to guess your router's password
6

Privacy tools

See which programs used your camera and microphone, check a password against known leaks, and delete files so they cannot be recovered.

  • Shows a program that is using the camera or microphone right now
  • Password check sends only 5 characters of a fingerprint, never the password
  • Secure delete detects SSDs, runs TRIM and points you to BitLocker
7

In your language, always watching

Choose English, Arabic or Afaan Oromoo when you install. Switch on live protection and NoorGuard can start with Windows and watch quietly from the tray.

  • Every screen and message translated, right-to-left in Arabic
  • Closing the window keeps it running in the tray
  • Works offline; only the options you switch on use the internet

How it works

Install and choose your language

Download the installer and pick English, Arabic or Afaan Oromoo. No account needed.

Scan

NoorGuard looks for viruses and checks your network and Windows settings, then shows what it found in plain words.

You decide

Choose what to block, remove or switch off. NoorGuard always asks first.

What NoorGuard does, honestly

  • Nothing is blocked, stopped, removed or switched off unless you press a button and confirm.
  • NoorGuard's own checks are not a full antivirus. Microsoft Defender does the real virus detection: keep Windows Security turned on.
  • It only sees what happens while it is running. Live protection needs the program to be open or in the tray.
  • It cannot see your router's password and never tries to guess it. It can only remind you to change it.
  • It is an early beta. Please try it yourself before relying on it, and tell us what you find.

Questions

Is NoorGuard free?

Yes. There is no account, no subscription and no advertising inside the app.

Will it block or delete anything by itself?

No. It warns you and lists what it finds. You press the button, and it asks before every block, removal or change.

Is it an antivirus?

Not on its own. It adds its own checks and can run Microsoft Defender's full scan for you, but you should keep Windows Security turned on.

Does it work in Arabic and Afaan Oromoo?

Yes. Choose the language when you install, or later in Settings. The translations are new, so corrections are welcome.

Does it send my data anywhere?

No, unless you switch on an option that needs the internet. The country lookup sends only an attacker's public address to ipwho.is, and the password check sends only the first 5 characters of a fingerprint (hash) to the Have I Been Pwned service. Both are off or on request.

Do I need administrator rights?

To install, no. To block a port or address, switch protections on, change the hosts file or read the failed sign-in log, yes. NoorGuard tells you when it is not running as administrator and offers to restart as one.

Does it protect me if the window is closed?

Yes, if you switched on live protection: closing the window keeps NoorGuard in the tray, and it can start with Windows. It cannot protect a PC while the program is not running.

How do I uninstall it?

Like any app: Windows Settings, then Apps, then NoorGuard, then Uninstall.
